# 🌌 hyprland-dots

Мои личные конфигурационные файлы (dotfiles) для тайлингового оконного менеджера **Hyprland**. Минималистичная, быстрая и функциональная среда для работы и отдыха на базе Wayland.

## 🛠️ Зависимости (Dependencies)

Перед установкой конфигурации убедитесь, что в вашей системе установлены следующие компоненты:

### Основное окружение и утилиты
* **Оконный менеджер:** `hyprland`
* **Блокировка и скринсейвер:** `hyprlock`, `hypridle`
* **Управление сессиями:** `hyprsession`
* **Панель:** `waybar`
* **Уведомления:** `mako`, `swaync`
* **Проводник:** `nautilus`

### Интерфейс и запуск программ
* **Меню запуска и утилиты:** `rofi`
* **Эмулятор терминала:** `alacritty`
* **Браузер:** `zen-browser` (Flatpak-версия `app.zen_browser.zen`)
* **Инфо-утилита:** `fastfetch`
* **Системный монитор:** `btop`

### Скриншоты и Обои
* **Утилиты скриншотов:** `grim`, `slurp`
* **Управление обоями / эффекты:** `awww`

### Bluetooth и Оборудование
* **Управление Bluetooth:** `blueman`, `blueman-applet`

### Темы, курсоры и плагины
* **Курсор:** `Bibata-Modern-Ice`
* **Менеджер плагинов Hyprland:** `hyprpm`
* **Плагин эффектов мыши:** `dynamic-cursors` (устанавливается через `hyprpm`)

## ⌨️ Горячие клавиши (Keybindings)

В качестве клавиши **`SUPER`** (или `$mainMod`) используется клавиша **Windows**.

### Управление окнами и системой
* `SUPER` + `Q` — Закрыть активное окно
* `SUPER` + `F` — Развернуть окно на весь экран (Fullscreen)
* `SUPER` + `V` — Переключить окно в плавающий режим (Floating)
* `SUPER` + `M` — Выйти из Hyprland

### Запуск приложений
* `SUPER` + `Return` (Enter) или `T` — Открыть терминал (`alacritty`)
* `SUPER` + `B` — Запустить браузер (`Zen Browser`)
* `SUPER` + `E` — Открыть проводник (`nautilus` в новом окне)
* `Ctrl` + `Shift` + `Escape` — Открыть системный монитор (`btop` в терминале)

### Инструменты и утилиты (Rofi / Скриншоты)
* `SUPER` + `R` — Открыть меню запуска приложений (`rofi`)
* `SUPER` + `W` — Открыть меню выбора обоев (`wallpaper-menu.sh`)
* `SUPER` + `S` — Сделать скриншот выбранной области (копируется в буфер обмена)
* `SUPER` + `H` — Открыть история буфера обмена (`cliphist` через меню `rofi`)
* `SUPER` + `L` — Заблокировать экран (`hyprlock`)

### 🔊 Мультимедиа (Управление звуком)
* `XF86AudioRaiseVolume` — Увеличить громкость на 5%
* `XF86AudioLowerVolume` — Уменьшить громкость на 5%

---

### 🗂️ Рабочие пространства (Workspaces)

* `SUPER` + `[1-9, 0]` — Переключиться на рабочее пространство от 1 до 10.
* `SUPER` + `SHIFT` + `[1-9]` — Переместить активное окно на рабочее пространство от 1 до 9.

###  mouse Управление мышью
* `SUPER` + `Левая кнопка мыши (ЛКМ)` — Перетащить окно по экрану.
* `SUPER` + `Правая кнопка мыши (ПКМ)` — Изменить размер окна.
